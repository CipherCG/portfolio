# 🚀 Personal Portfolio Website

Welcome to the repository for my personal developer portfolio! This site showcases my projects, technical skills, coursework, and coding journey. 

---

## ✨ Features

- **Responsive Design:** Optimized for all screen sizes (mobile, tablet, desktop).
- **Dark / Light Mode:** Built-in theme switcher using modern CSS variables and JavaScript.
- **Accessible (a11y):** Built with semantic HTML, keyboard-navigable components, and high-contrast styling.
- **Lightweight & Fast:** Pure HTML5, CSS3, and Vanilla JavaScript—no extra dependencies or heavy frameworks.

---

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3 (CSS Variables, Flexbox, CSS Grid)
- **Scripting:** Modern JavaScript (ES6+)
- **Hosting:** GitHub Pages
